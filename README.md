# 🌐 Real-Time Streamlit Dashboard

## 📌 Project Overview
A real-time dashboard built using Streamlit that displays live data from APIs like weather, cryptocurrency, and random user generator.

## 🚀 Features
- 🌤 Live weather updates (Open-Meteo API)
- ₿ Bitcoin live price (Binance API)
- 👤 Random user generator (RandomUser API)
- 📊 Interactive Streamlit UI
- 🌍 Sidebar city selection
- 🔄 Auto-refresh support

## 🛠 Tech Stack
Python, Streamlit, Requests, Pandas, REST APIs

## 📡 APIs Used
- Weather API: https://api.open-meteo.com  
- Crypto API: https://api.binance.com  
- User API: https://randomuser.me  

## ▶️ Run Locally
git clone https://github.com/YOUR_USERNAME/streamlit-dashboard.git  
cd streamlit-dashboard  
pip install -r requirements.txt  
streamlit run app.py

streamlit
